SMARTCOAL GOVERNANCE — SIH MVP

1. Install Python 3.11+ (Python 3.13 is okay).
2. Open this folder in VS Code.
3. Open Terminal in this folder.
4. Create a virtual environment:
   python -m venv venv

5. Windows PowerShell:
   .\venv\Scripts\Activate.ps1

   If PowerShell blocks activation, use Command Prompt:
   venv\Scripts\activate

6. Install Flask:
   pip install -r requirements.txt

7. Start:
   python app.py

8. Open in browser:
   http://127.0.0.1:5000

The prototype uses synthetic demo data. It is not connected to real government systems.
